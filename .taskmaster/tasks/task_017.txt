# Task ID: 17
# Title: Implement AI Query Analysis and MCP Tool Selection System
# Status: pending
# Dependencies: 7, 8, 9
# Priority: high
# Description: Develop an intelligent system that leverages Gemini AI to analyze user queries, infer intent, and automatically select the appropriate MCP tools for Podio data operations, incorporating context management and conversation history analysis.
# Details:
Integrate Gemini AI (Pro/Flash) to process incoming user queries, using advanced prompt engineering to extract user intent and relevant entities. Design a query analysis pipeline that parses the user's natural language input, references recent conversation history, and maintains context across multi-turn interactions. Implement logic to map inferred intents to specific MCP tools (e.g., get_item_basic, get_comments, get_files) by defining a tool selection schema and decision rules. Ensure the system can handle ambiguous or compound queries by decomposing them and selecting multiple tools if needed. Store and retrieve conversation context and history from Supabase to inform tool selection and maintain continuity. Provide a transparent reasoning trace for tool selection to support debugging and future improvements. Ensure the system is extensible for new MCP tools and supports fallback or clarification prompts when intent is unclear.

# Test Strategy:
Create a comprehensive suite of test queries covering all supported MCP tools, including ambiguous, compound, and context-dependent questions. Simulate multi-turn conversations to verify context management and correct tool selection across turns. Validate that the system selects the correct MCP tool(s) for each query and provides reasoning traces. Test with edge cases such as incomplete queries, conflicting intents, and unsupported operations. Perform manual review of AI-generated intent mappings and tool selections. Monitor error rates and fallback scenarios. Ensure integration with Supabase for context persistence and retrieval functions as expected.
